# Road image example

The preferred demonstration image is the pothole image from the read-only source archive:

`RoadSense-AI-archive/data/Road Issues/Pothole Issues/1_jpg.rf.165df17c20f06ab9f6e719388333fc5c.jpg`

It was not copied into this repository because the archive does not include clear redistribution licensing information. The dataset is identified in the original project model card as the public Kaggle Road Issues Detection Dataset:

https://www.kaggle.com/datasets/programmerrdai/road-issues-detection-dataset

Download a permitted copy from the source, then use it with the Detect Damage page. Do not upload it to the RAG Knowledge Chat workflow.
